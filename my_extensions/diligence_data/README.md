# 工商快照格式（脱敏）

每个 `.txt` 是一家公司的工商快照，由人从公开渠道整理而来；`counterparty_due_diligence` 只读这里的文件，不联网。

- `sample_b_*.txt`、`sample_c_*.txt`：**全部为合成数据**，用来检验规则对"多项高风险"和"无风险"两种情形的行为，不对应任何真实公司。

格式：
```
取数日期：YYYY-MM-DD            ← 必填，所有"近 N 个月"都以它为基准
企业名称：... / 登记状态：... / 成立日期：... / 注册资本：...万元 / 实缴资本：...万元 / 参保人数：N / 法定代表人：...
## 风险统计                      ← "项目：条数"
## 动态                          ← 每行 "YYYY-MM-DD 事件描述"，描述沿用企查查动态的措辞
```
